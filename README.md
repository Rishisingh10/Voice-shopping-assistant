# Voice Command Shopping Assistant

**Live Application:** https://voice-shopping-assistant-3ffidacfvf2nyqymn8qx9n.streamlit.app/

## Project Approach

I built a dependency-minimal Streamlit application for a voice-command shopping assistant. The application processes voice commands to manage shopping items, provides categorization and suggestions, and presents the results through a simple and user-friendly interface.

## Features

- Voice-based shopping commands
- Add and remove shopping items
- Automatic item categorization
- Smart shopping suggestions
- Simple and responsive interface
